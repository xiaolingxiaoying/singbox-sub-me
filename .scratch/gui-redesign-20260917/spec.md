# GUI 重新设计

Status: claimed

## 需求

简洁、整齐、现代，围绕完整订阅导入和本机 sing-box 控制设计。保留 GPUI 和共享 client-core 控制面，保留订阅、节点、连接、日志、设置能力。

## 现状证据

- `crates/sbgui/src/main.rs`：概览同时在标题栏、页头、蓝色主卡和指标卡重复内核状态与操作。
- `dashboard_hero` 将 core_running 描述为网络就绪及保护连接，实际并不能证明网络接管或出口连通性。
- `network_path` 用连接数量表示公网出口，应避免把连接数量当作出口验证。
- 现有代码、DESIGN.md、client-core 和资源目录已有未提交修改，后续增量修改必须保留。

## 产品约束

使用 ClientSnapshot 作为显示依据，以 ClientCommand 执行操作。不得把演示节点、速率或连通性写入实际界面。内核、系统代理、TUN 配置与出口可用性分别表达。

## 设计方向

Operate 模式；浅色桌面网络控制台，中文系统字体，克制蓝色主操作，细边框、明确行对齐与标准设置控件。七个结构参照为：系统网络设置、连接管理器、文件管理器、桌面设备控制台、资源监视器、表格式网络诊断器、订阅资料库。种子 d45b199d 分配第四项桌面设备控制台；以可操作状态及层级为中心。

候选布局：A 连接优先；B 节点优先；C 状态与流量优先。生成设计预览后等待布局选择，再实现。图中数据为演示数据。

## 验收

- 首页有清晰主操作，状态不重复堆叠，文案不夸大网络能力。
- 六个页面保持统一间距、字体、控件、列表与空状态。
- 保持现有命令行为和用户修改。
- Rust 格式与 sbgui 编译检查，条件允许时验证原生窗口视觉和尺寸适配。

### 已实现

- 236px 控制侧栏，规则/全局/直连可直接选择。
- 系统代理与 TUN 模式常驻；TUN 在内核运行或启动中锁定，提示停核后切换。TUN 的选择状态不冒充运行状态。
- 6 个双列导航块，订阅摘要、实时上传下载与内核状态。
- 紧凑页头与唯一常驻内核操作；概览不再使用蓝色大横幅、重复四指标、未经检测的公网出口。
- 节点分组与网格；自动组不发送手动切换，点击测试停止事件传播。
- 订阅列表淡色选中，设置页分隔行。
- 内嵌 SVG 线性图标；GPUI 原生真实样本折线，无伪造速率、峰值或地理数据。
- 默认1080×760，最小860×640；连接表支持横向滚动。
