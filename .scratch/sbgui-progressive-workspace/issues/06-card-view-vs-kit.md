# 概览页的卡片式指标带与 kit"避免卡片网格"相冲

Status: needs-triage
Type: task

## 现象

设计资源包明确不鼓励卡片网格，而概览页当前是"连接状态主卡 + 当前节点与流量卡 + 指标带"的组合，视觉上仍以卡片为主。

## 冲突点

原型自己的概览稿也用了卡片承载指标。所以这不是实现跑偏，是规范与原型不一致，需要维护者判定哪一边是准绳：

1. 以 `design-kit` 文字规范为准，概览改成分节列表，卡片只留一处；
2. 以原型稿为准，把 kit 的这条视为针对"其他页面不要滥用卡片"；
3. 折中：概览保留一张主卡，其余指标降为无框数据行。

## 影响

判定结果决定概览页是否还要再改一轮，也决定 `spec.md` 的验收映射里"视觉签核"能否签字。在此之前不要动概览页。
