# Preserve the Rust control-plane boundary while matching upstream protocol outputs

sbctl keeps its Rust control plane and uses `sing-box-yg` and `vps-sub-meter` as behavioral references for the five Managed protocols and the sing-box/Clash subscription outputs. It retains three Subscription formats (sing-box JSON, Clash/Mihomo YAML, and URI text), with the first two required to remain compatible with `vps-sub-meter` consumers. It does not copy remote shell orchestration, Basic Auth or query-token bypasses, shared UUID credentials, automatic migration, or takeover of an existing upstream deployment. This preserves independent proxy credentials, path-only Subscription credential authentication, and the existing reversible lifecycle while still producing familiar client nodes.
